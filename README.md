# 🛠️ PATH FORGE
> Custom-crafted learning pathways tailored to your target role.

## 🚀 Concept
PATH FORGE helps users escape "tutorial hell" by generating personalized, project-based career roadmaps based on their exact current skills and target job roles.

## 🛠️ Tech Stack (TBD)
- **Frontend:**      

| *Technology / Library* | *Version / Type* | *Description & Usage* |
| :--- | :--- | :--- |

| **Lucide Icons** | CDN (`unpkg`) | Lightweight vector iconography throughout the navigation, controls, and UI cards |
| **Canvas Confetti** | v1.9.2 CDN | Particle burst animation engine triggered upon completing roadmap milestones |
